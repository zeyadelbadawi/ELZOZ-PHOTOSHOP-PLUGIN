## PSD templates: what they are and are not

- Written with **ag-psd** and checked by **ag-psd** and **psd-tools** (an independent parser): canvas size, nesting and layer kinds (text, Smart Object, pixel, group) match (`templates/psd-tools-verification.json`).
- Text layers have no pre-rendered pixels, so **Photoshop will ask to update text layers when opening them; choose Update**. Smart Objects embed a 48x48 PNG placeholder.
- They have **not** been opened in Photoshop from this environment. A Photoshop-authored template should also be tested.
