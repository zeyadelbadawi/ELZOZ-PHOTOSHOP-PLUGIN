│ QUICK START                                                                  │
└──────────────────────────────────────────────────────────────────────────────┘

  Build:
  $ npm install
  $ npm run build

  Development:
  $ npm run watch              # Watch mode
  
  Load in Photoshop:
  $ npm run uxp:load           # Load plugin
  $ npm run uxp:reload         # Reload after changes

  Debug:
  $ npm run uxp:debug          # Debug mode
