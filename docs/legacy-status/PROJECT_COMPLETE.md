## 🚀 How to Use

### Step 1: Build
```bash
npm install
npm run build
```

### Step 2: Load in Photoshop
```bash
npm run uxp:load
```

### Step 3: Test
1. Open Setup tab
2. Select Excel file
3. Select image folder
4. Select PSD template
5. Go to Mapping tab
6. Create layer mappings
7. Go to Execute tab
8. Click RUN
9. View results in Analytics

## 🐛 Known Limitations (Phase 1)

⚠️ Batch processing is **simulated** (not real Photoshop integration)
⚠️ Images **not actually** inserted into PSD
⚠️ Files **not exported** to disk
⚠️ Data limited by localStorage (~5-10MB)

### To Be Fixed in Phase 3
- [ ] Real Photoshop API integration
- [ ] Image insertion engine
- [ ] Auto-export functionality
