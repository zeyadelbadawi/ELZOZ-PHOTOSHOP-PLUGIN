LAYER DETAIL: FILE OPERATIONS
------------------------------

When user clicks "Select Excel" button:

1. SetupPanel Component
   └─ handlePickExcel() function called
      │
      ├─ fileOps.pickExcelFile() [UXPBridge.js]
      │  │
      │  ├─ Check if fs.getFileForOpening exists
      │  │  (If not, throw "File system API not available" error)
      │  │
      │  ├─ Call fs.getFileForOpening({ types: ['xlsx', 'xls', 'csv'] })
      │  │  (Opens native file picker dialog)
      │  │
      │  ├─ If file selected:
      │  │  ├─ Read file as binary data
      │  │  └─ Return { file, fileName, path, data }
      │  │
      │  └─ If cancelled:
      │     └─ Return null
      │
      ├─ If success:
      │  ├─ Parse with XLSX library
      │  ├─ Extract columns and rows
      │  ├─ Update ProjectContext:
      │  │  ├─ excelPath
      │  │  ├─ excelFile
      │  │  ├─ excelData (array of rows)
      │  │  ├─ excelColumns (array of column names)
      │  │  └─ excelRowCount
      │  │
      │  └─ Update UI:
      │     ├─ Button changes to "✅ Excel Selected"
      │     └─ Data preview table appears
      │
      └─ If error:
         └─ setError() displays error message

CSS HIERARCHY (Scrolling)
-------------------------

html { width: 100%; height: 100%; }
body { width: 100%; height: 100%; }

#root {
  width: 100%;
  height: 100%;
  display: flex;
}

.panel {
  display: flex;
  flex-direction: column;
  width: 100%;
  height: 100%;
  overflow: hidden;  ← Main panel container
}

.panel > div:last-child {
  flex: 1;
  overflow: auto;    ← Scrollable content area
}

Scrollbars appear automatically when:
  - Content height > Container height
  - overflow: auto is set
  - Container has fixed height


ERROR HANDLING FLOW
-------------------

File Picker Called
  │
  ├─ API Available?
  │  ├─ NO  → throw Error("File system API not available")
  │  │       → setError() displays in UI
  │  │       → User sees: ⚠️ message
  │  │
  │  └─ YES → Proceed
  │
  ├─ Dialog Opened
  │  ├─ User Cancels → return null
  │  │                → No error, just no file selected
  │  │
  │  └─ User Selects → Proceed
  │
  ├─ File Processing
  │  ├─ Read Success → Parse & Store
  │  │
  │  └─ Read Error → throw Error("Read failed: reason")
  │                  → setError() displays
  │                  → User sees: ⚠️ message
  │
  ├─ Parse Success
  │  ├─ Update state
  │  └─ Update UI
  │
  └─ Parse Error
     └─ throw Error("Parse failed: reason")
        → setError() displays
        → User sees: ⚠️ message


WHAT'S FIXED
-------------

✓ UXP API Initialization (UXPBridge.js)
  Before: const fs = localFileSystem || {};
          → fs might be undefined, causing failures
  
  After:  let fs = {};
          if (typeof window !== 'undefined') {
              try {
                  const uxp = window.uxp || {};
                  fs = uxp.storage ? uxp.storage.localFileSystem : {};
              }
          }
          → Safely checks if API exists before using

✓ Error Handling (All file picker methods)
  Before: No error handling, silent failures
  
  After:  try-catch blocks with clear error messages
          → User sees what went wrong

✓ CSS Layout (styles.css)
  Before: Missing root element styling
          → Scrolling didn't work properly
  
  After:  Added html, body, #root styling
          → Proper flexbox layout with scrollable panels
