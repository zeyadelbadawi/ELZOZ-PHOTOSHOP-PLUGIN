# UI preview screenshots

Captured from the browser harness (`npm run harness && node tests/harness/walkthrough.js`):
the real React app and services running in Chromium against the fake Photoshop host.

**These are not Photoshop screenshots.** UXP renders `sp-button`, selects and inputs
with native Spectrum widgets and supports less CSS than Chromium, so final visual QA
must be done in Photoshop. Widths: 320 px (default docked), 260 px (narrow), 520 px (wide);
`31`/`32` are Arabic, `32` simulates Photoshop 23.5 (text compatibility notice).
